# AutobiographicAI recordings

This public archive contains compressed copies of the available sound recordings and the aggregate transcript.

- Audio: mono Opus at 16 kHz and 24 kbps, intended for speech
- Audio files: 266 compressed files, covering every valid `.m4a` source found
- Aggregate transcript: `Sound recordings transcription.pdf`
- The source recording `Recording (248).m4a` was an invalid 84-byte M4A file and could not be decoded; the transcript documents that limitation.

The transcript is an audio transcription and user-supplied classification record. Labels in the PDF are not independent verification of claims in the recordings.
