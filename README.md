# AutobiographicAI recordings

This public archive contains compressed sound recordings and an aggregate transcript.

- Audio: lossy mono Opus, encoded from 16 kHz input at a target of 24 kbps, intended for speech.
- Audio files: 388 compressed files, totaling approximately 1.50 GB.
- Coverage: the original 330 available recordings through `Recording (331).m4a`, plus recordings 1292-1349 added on 16 November 2026.
- Recordings 332-1291 are not included in this audio archive.
- Aggregate transcript: [Sound recordings transcription.pdf](Sound%20recordings%20transcription.pdf).
- New batch metadata and checksums: [recordings-1292-1349.json](recordings-1292-1349.json). The source SHA-256 identifies the captured M4A bytes; the audio SHA-256 identifies the compressed Opus file.

The source recording `Recording (248).m4a` was an invalid 84-byte M4A file and could not be decoded; the transcript documents that limitation.

The transcript is an audio transcription and user-supplied classification record. Labels in the PDF are not independent verification of claims in the recordings.
